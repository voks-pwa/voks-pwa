# Profile Completion Specification

Profile Complete MUST follow these rules.

---

## Mandatory Basic Information

- Full Name
- Display Name
- Phone Number
- Birthday
- Gender
- Province
- City
- Favorite Program
- Favorite Music

---

## Mandatory Social

- Instagram
- TikTok

---

## Optional Social

These fields DO NOT affect profile completion.

- Facebook
- Youtube
- Threads
- Website

---

## Avatar

Avatar is optional.

Changing avatar must never invalidate profile completion.

---

## Completion Rule

Profile Complete =

Basic Information Complete

AND

Instagram Filled

AND

TikTok Filled
