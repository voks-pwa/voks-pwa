Reward Rules

XP must never become negative.

Reward can never be redeemed twice.

History is immutable.

Reward transaction must always be server-validated.

Frontend never deducts XP directly.

Definition of Done

Reward redeemed once.

History created.

XP deducted correctly.

No duplicate transaction.
