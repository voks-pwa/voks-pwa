bantu saya menganalisan dan mengembangkan fitur mission dan Reward pada VOKS NEXT ini. Voks next adalah PWA yang bertujuan untuk platform mendengarkan streaming dan melihat streaming visual dari Voks Radio. Karena kita membutuhkan data jumlah pendengar yang menggunakan PWA ini maka kita membuat PWA ini User harus Login/Sign up. dan sebagai pembeda atau nilai lebih buat user yang sudah Sign up, saya ingin menambahkan fitur mission dan reward. missionnya dibuat pada wordpress melalui https://voksradio.com/wp-json/wp/v2/missions?_embed. mission untuk user ini seperti Daily Checkin, Share link PWA, Referral PWA, atau mission lainnya yang nanti bisa saya buat di Wordpress sesuai kebutuhan. Setiap user yang berhasil melakukan mission ini akan mendapatkan VXP atau Voks Experience Point. VXP ini bisa di Redeem dengan hadiah hadiah pada Reward Store yang juga di buat melalui Wordpress Api https://voksradio.com/wp-json/wp/v2/reward?_embed.

kemudian saya juga ingin mengoptimalkan dashboard admin untuk bagian analitik saya ingin ditampilkan data pengguna PWA ini. seperti jumlah user, DAU, MAU, dan lainnya. seperti klik banner promo, yang play streaming berapa, page mana yang paling banyak di kunjungi dan diklik. program mana yang banyak di favoritkan, penyiar mana yang paling banyak favoritkan dan lainnya. kebutuhan data analitik ini untuk menarik calon klien dan report ke klien jadi kamu bantu berikan saran matrik apa saja yang harus ada pada analitik ini.
